## 相关步骤 - 视频为准

### 三、创建本地 WordPress 站点（宝塔 Windows 面板）

1. 在宝塔 Windows 面板中添加站点
   - 域名：guaqi.test
   - 网站目录：D:\guaqitest\guaqi.test
   - PHP 版本：选择 PHP 8.2

2. 开启 HTTPS（使用本地自签证书）
   1. 在宝塔面板的站点设置中，找到 SSL 配置。
   2. 生成或导入本地自签 SSL 证书。
   3. 开启强制 HTTPS，让浏览器信任本地自签证书。

3. 设置伪静态
   1. 在宝塔面板的站点设置中，找到"伪静态"选项，选择 WordPress 伪静态规则并保存。
   2. 如果下拉列表中没有 WordPress 规则，可以手动填入以下规则：

```
location / {
    try_files $uri $uri/ /index.php?$args;
}

rewrite /wp-admin$ $scheme://$host$uri/ permanent;
```

4. 数据库与安装
   1. 在宝塔面板中创建一个空数据库（MySQL 8.0）。
   2. 浏览器打开 https://guaqi.test，按 WordPress 页面提示完成安装。
   3. 安装完成后进入 WordPress 后台，打开 设置 → 固定链接。

5. 固定链接设置（重要）
   1. 选择"自定义结构"，在输入框中填入以下内容并保存：

```
/%post_id%.html
```

   2. 注意：固定链接必须修改，不能保留"朴素"默认结构。使用 /%post_id%.html 格式有利于 SEO 和 URL 可读性。

6. 数据库报错问题处理
   1. 问题现象：建站勾选创建数据库却未生成库、创建数据库提示 Error 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)
   2. 解决步骤：
      1. 进入宝塔面板的"数据库"页面
      2. 点击"root 密码"选项
      3. 修改 root 密码并保存
      4. 重新尝试创建数据库即可

> **注意！** 安装完成后，到「设置 - 常规」中，查看站点地址和 WordPress 地址是否为 https
