## 环境说明-以视频为准

- PHP 环境（建议 PHP 8.2，禁止使用 8.2 以上版本）
- MySQL （建议 MySQL 8.0）
- Node.js
- SSL 证书（本地自签证书，用于开启 HTTPS）
- WordPress 伪静态支持（在宝塔站点管理中设置伪静态）

PHP 扩展要求：

安装 PHP 8.2 后，请检查以下扩展是否已安装并启用：

- opcache：用于 PHP 代码缓存，提升执行性能
- redis：用于 Redis 对象缓存支持

在宝塔面板中检查及安装方法：

1. 进入宝塔面板的"网站"页面
2. 点击站点对应的"设置" → "PHP命令行版本" → 查看已安装的扩展列表
3. 或者在"软件商店" → "PHP-8.2" → "设置" → "安装扩展"中查看和安装
4. 如果 opcache 或 redis 未安装，在扩展列表中点击"安装"即可
5. 安装完成后重启 PHP 服务使配置生效
