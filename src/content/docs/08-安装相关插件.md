## 相关步骤

### 四、安装和配置 WordPress 插件

1. 按顺序安装并启用插件

   请严格按照以下顺序操作：

   1. 第一步：安装并启用 WPGraphQL
      1. 进入 WordPress 后台 → 插件 → 安装插件
      2. 搜索 "WPGraphQL"，点击"现在安装"
      3. 安装完成后点击"启用"
   2. 第二步：安装并启用 Redis Object Cache
      1. 进入 WordPress 后台 → 插件 → 安装插件
      2. 搜索 "Redis Object Cache"，点击"现在安装"
      3. 安装完成后点击"启用"
      4. 启用后，进入插件设置页面，点击"启用对象缓存"
      5. 注意：如果在 Redis 设置页面提示无法访问 Redis，请按以下步骤排查：
         1. 进入宝塔面板 → "软件商店" → "已安装"
         2. 查看是否已安装 Redis 服务（不是 PHP 的 redis 扩展）
         3. 如果未安装 Redis 服务，点击"安装"进行安装
         4. Redis 服务安装完成后，PHP 的 redis 扩展可以自动连接，无需额外配置
         5. 如果已在 PHP 中安装 redis 扩展但软件商店中未安装 Redis 服务，可能是因为系统内存不足导致 Redis 服务安装失败，此时需要单独安装 Redis 服务
         6. 安装完成后返回 WordPress 后台，重新点击"启用对象缓存"
   3. 第三步：安装并启用 Safe SVG
      1. 进入 WordPress 后台 → 插件 → 安装插件
      2. 搜索 "Safe SVG"，点击"现在安装"
      3. 安装完成后点击"启用"
   4. 第四步：启用瓜奇插件
      1. 进入 WordPress 后台 → 插件
      2. 在插件列表中找到"瓜奇"插件，点击"启用"
      3. 瓜奇插件由安装脚本自动放置在 guaqi.test/wp-content/plugins/guaqi/ 目录下
