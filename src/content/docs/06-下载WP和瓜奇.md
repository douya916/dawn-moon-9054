## 相关步骤 - 视频为准

### 二、下载 WordPress、瓜奇插件和前端源码

1. 创建项目文件夹
   1. 方式一（命令行创建）：打开 PowerShell，执行：

```powershell
mkdir D:\guaqitest
cd D:\guaqitest
```

   2. 方式二（手动创建）：在 D 盘（或其他盘符）手动创建一个名为 guaqitest 的文件夹，然后打开 PowerShell 切换到该目录：

```powershell
cd D:\guaqitest
```

2. 下载并运行安装脚本
   1. 在运行安装脚本之前，建议先设置 TLS 1.2，避免下载时出现加密协议错误：

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
```

   2. 然后执行：

```powershell
irm https://7b2.com/guaqi-dev/setup.ps1 -OutFile setup.ps1
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

   3. 脚本执行过程说明：
      - [1/4] 下载 WordPress 核心文件
      - [2/4] 下载前端源码（client.zip）
      - [3/4] 下载瓜奇插件（plugin）
      - [4/4] 创建 runtime-plugins-dev 目录链接
      - 脚本会自动执行 pnpm install，安装前端项目所需的所有依赖包（共约 1177 个包）
      - 第一次安装依赖会稍久一些，请耐心等待，不要中断脚本
      - 脚本最后会尝试信任本地 HTTPS 证书，如果报错 "Missing script: https:trust"，可以忽略，不影响后续使用
      - 看到依赖安装完成（Done in Xm Xs）且无其他错误提示，表示脚本执行完毕

3. 脚本运行完成后的目录结构
   - D:\guaqitest\
   - ├─ guaqi.test\                 WordPress 站点目录
   - ├─ node\client\                前端源码
   - │  ├─ layers\custom\           客户自定义前端代码
   - │  ├─ runtime-plugins\         客户自己开发的插件源码
   - │  ├─ node_modules\            前端依赖包（自动安装）
   - │  └─ .env                     环境变量配置文件
   - ├─ setup.ps1
   - └─ guaqi-dev-guide.md

4. 自动创建的目录链接
   1. 安装脚本会自动创建一个目录链接：
   2. D:\guaqitest\guaqi.test\wp-content\plugins\guaqi\runtime-plugins-dev
   3. → D:\guaqitest\node\client\runtime-plugins
   4. 说明：WordPress 和 Node.js 读取同一份插件源码。无需手动创建 runtime-plugins-dev，也不要复制一份插件进去。
