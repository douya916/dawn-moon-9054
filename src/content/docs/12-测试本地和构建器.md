## 相关步骤 - 以视频为准

### 每次刚打开 powershell 后，pnpm dev 之前，执行一次以下命令。关闭 powershell 窗口后，命令就会失效，下次打开 shell 重新执行一次即可

```powershell
$env:NODE_OPTIONS="--use-system-ca"
```

### 然后再运行 pnpm dev

> **警告：** 浏览器访问 localhost:3000 时，如果第一次访问没有反应，可以刷新一下页面，看视频中的操作

### 清理缓存的命令

```powershell
Remove-Item -Recurse -Force .nuxt, .data -ErrorAction SilentlyContinue
```
